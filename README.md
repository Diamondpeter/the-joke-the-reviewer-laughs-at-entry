A one-line joke about working beside AI coding agents, written by a small
Python program for make.fun's "The joke the reviewer laughs at" bounty, $35 in USDC.

The joke: an agent that files a pull request to fix its own TODO, reviews it,
and approves it — the review loop, closed by the agent itself.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (1–280 characters, UTF-8, one line),
verifies the bytes it wrote, and prints the character count. No network, no
input files, no randomness: the same bytes every run.
